# DS18B20 driver

One-wire digital temperature sensor on any GPIO.

## Hardware

- DS18B20 data pin → MCU GPIO
- **4.7 kΩ** pull-up from DATA to 3V3
- VDD → 3V3, GND → GND

## PlatformIO deps

Included via `drivers` library: OneWire, DallasTemperature.

## API

| Function | Description |
|----------|-------------|
| `ds18b20_init(data_pin)` | Start OneWire bus on `data_pin` |
| `ds18b20_read_celsius(&out)` | Blocking read; `false` if disconnected |

## Example

```cpp
#include <drivers/ds18b20.h>

void setup() {
    Serial.begin(115200);
    drivers::ds18b20_init(D2);
}

void loop() {
    float c = 0.0f;
    if (drivers::ds18b20_read_celsius(&c)) {
        Serial.printf("Temp=%.1fC\n", c);
    }
    delay(1000);
}
```

## Gotchas

- **~750 ms blocking** per read with `setWaitForConversion(true)` — poll only in `loop()`, never in AsyncWebServer callbacks.
- Single sensor on bus (index 0) — extend driver if multiple devices needed.

## Bench checklist

1. Serial shows plausible °C at room temperature.
2. Disconnect sensor → read returns `false`, no crash.
